# Projeto - Sistema de Gestão de Loja de Roupas

## Organização
- index.html: entrada do projeto
- pages/: telas HTML
- css/: estilos
- js/: JavaScript
- java/: código Java separado do front-end
- assets/: imagens e ícones

Abra a pasta no VS Code e execute o index.html usando Live Server.
